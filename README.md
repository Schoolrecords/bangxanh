# Bảng Xanh
App giáo án trình chiếu PPT cho giáo viên tiểu học.
Chọn môn → chọn lớp → chọn tuần → mở bài giảng trên Google Drive.

Xem tại: https://schoolrecords.github.io/bangxanh
Mở bằng Chrome/Edge rồi bấm **Cài đặt** là dùng như app riêng, mất mạng vẫn mở được.

- Thêm bài giảng: sửa file `assets/js/links.js`
- Đặt ngày khai giảng & lịch nghỉ (để app biết đang ở tuần mấy): sửa mục `namHoc` trong `assets/js/data.js`
